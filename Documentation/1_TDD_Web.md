# Technical Design Document (TDD)
## Frontend wireframes
System Design
The system will be a web-based front-end application. Environmental data will be stored locally in structured files, and JavaScript will control logic and interactions.
Component Interaction
* User Interface Layer: displays visuals, timeline, and buttons
* Logic Layer: handles timeline movement, comparisons, and animations
* Data Layer: stores environmental data for each year
* Animation Layer: manages visual transitions and effects
Functionalities and Implementation Plan
* Timeline slider implemented using JavaScript
* Environmental data stored in JSON format
* CSS and JavaScript used for animations
* Comparison mode controlled by a toggle switch
* Visual updates triggered by timeline interaction
Data Structure (Example)
Environmental data will be stored in JSON format with the following fields:
* year
* temperature
* seaLevel
* forestCoverage
* animalPopulation
* pollutionLevel
