# Functional Design Document (FDD)
## General description
Project Overview
The project is an educational interactive website that visualizes how the Earth may change from 2026 to 2126 if humanity ignores environmental issues. The website aims to raise awareness by showing the long-term consequences of climate inaction in a clear and engaging way.
Brief Description of the Project
The website allows users to scroll through a timeline from 2026 to 2126 and observe changes in nature, oceans, and wildlife. Users can compare two possible futures: one where people care about the environment and one where they ignore it. Visual animations help users understand the impact of human behavior on the planet.
Functional Requirements
The system must:
* Display an interactive timeline from 2026 to 2126
* Allow users to scroll or drag through different years
* Visually show environmental changes over time
* Provide a comparison mode ("If we care" vs. "If we ignore")
* Include animations such as melting glaciers, wildfires, and disappearing animals
* Display short facts or statistics for each selected year
Main Features
* Interactive timeline slider
* Environmental visualization for each year
* Comparison toggle between two futures
* Animated environmental effects
* Informational pop-ups with data and explanations
User Stories
* As a user, I want to scroll through the timeline so I can see how the world changes over time.
* As a user, I want to compare two futures so I can understand the consequences of our actions.
* As a user, I want to see animations so the experience feels realistic and engaging.
* As a user, I want to read short facts so I can learn what is happening in each year.
User Interface Design
The user interface is clean and visual:
* A large main area showing the environment
* A timeline slider at the bottom of the screen
* A toggle switch for comparison mode
* Information panels showing facts and statistics
Wireframes / Mockups (Description)
* Header with project title and short introduction
* Central visual area with animated environment
* Timeline slider from 2026 to 2126
* Side or bottom panel with environmental data
* Toggle button to switch between scenarios
